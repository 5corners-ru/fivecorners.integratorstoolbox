Полные настройки расширения

Инструменты

Включайте и отключайте инструменты по отдельности. После изменения обновите вкладку с дизайнером БП (F5).

Тема поля ввода

Цветовая схема подсвечиваемого поля выражения.

Цвета элементов подсветки

Задайте цвет для каждого типа элемента. Кнопка «По умолчанию» возвращает стандартный цвет.

Элемент Пример Цвет

Коробочный Битрикс24

Подсветка работает на всех облачных Битрикс24. Для коробочных порталов добавьте свой домен в список разрешённых.

Укажите URL портала (например https://portal.5corners.ru), нажмите «Добавить», подтвердите доступ, затем обновите вкладку с дизайнером БП (F5).
