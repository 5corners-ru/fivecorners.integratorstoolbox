Коробочный Битрикс24

Подсветка работает на всех облачных Битрикс24. Для добавления коробочных Битрикс24 добавьте свой домен в список разрешённых.

Укажите URL портала (например https://portal.5corners.ru), нажмите «Добавить», подтвердите доступ, затем обновите вкладку с дизайнером БП (F5).
