## 5 УГЛОВ. Инструменты интегратора Bitrix24 — 07.07.2026 — Два исправления в дизайнере БП

**Версии:** расширение (Chrome/Edge) 1.9.8
**Сделал:** Gennadiy

🐞 **Исправлено**
— Поле «Поиск в списке…» в больших выпадающих списках внутри всплывающих окон дизайнера БП (например диалог «Вставка значения») больше не наезжает на соседний текст — ссылки «Параметры шаблона / Переменные / Константы / Глобальные константы» над списком.
— Красный значок ошибки на ноде БП больше не срабатывает ложно при открытии дизайнера. Раньше индикатор мог сработать до того, как Битрикс успевал загрузить переменные/константы/параметры шаблона — и ноды помечались как «битые», хотя реальных ошибок не было.

## 5 УГЛОВ. Инструменты интегратора Bitrix24 — 25.06.2026 — Новый облик, темы и подготовка к публикации

**Версии:** расширение (Chrome/Edge) 1.9.6
**Сделал:** Pavel Larkin

✨ **Новое**
— Каждый инструмент теперь включается и выключается отдельно — прямо на главном окне расширения: подсветка синтаксиса, поиск в списках и полях, поиск по нодам, подсветка нод с ошибками.
— Переключатель темы интерфейса: Авто (как в системе), Светлая, Тёмная.
— В подвале — ссылка «написать о проблеме или предложить идею» (форма обратной связи) и ссылка на каталог наших модулей.

🛠 **Улучшено**
— Полностью новый, современный вид главного окна и страницы настроек, с фирменным знаком «5 УГЛОВ» и поддержкой светлой и тёмной тем.
— Полные настройки открываются отдельной вкладкой во всю ширину — раньше это было тесное окошко, где таблица цветов не помещалась.
— Список добавленных порталов стал аккуратнее и компактнее.
— Расширение запрашивает меньше прав при установке — больше нет пункта «чтение истории посещений».
— Расширение упаковано и готово к публикации в Chrome Web Store.

🐞 **Исправлено**
— Портал, добавленный кнопкой «Добавить текущий портал», теперь надёжно сохраняется (раньше мог не записаться, если окно закрывалось на запросе доступа). После добавления показывается подтверждение «🎉 Текущий портал добавлен в расширение!».

## 5 УГЛОВ. Инструменты интегратора Bitrix24 — 24.06.2026 — Поиск по нодам и автосканер ошибок

**Версии:** расширение (Chrome/Edge) 1.6.0
**Сделал:** Gennadiy

✨ **Новое**
— Поиск по нодам в правой панели дизайнера бизнес-процессов: вводишь название — панель сворачивает лишние группы и показывает только подходящие действия. Больше не нужно листать весь список вручную.
— Автоматический поиск «битых» нод: расширение само подсвечивает на схеме те действия, в которых используются отсутствующие или недоступные поля, переменные и константы.
— Поиск внутри выпадающих списков: рядом с каждым большим списком на формах БП появляется поле «Поиск в списке…» — отбор по части слова, выбор мышкой или стрелками ↑↓ + Enter.

🛠 **Улучшено**
— Поиск в списках больше не перекрывает штатный интерфейс Битрикса: для обычных выпадашек и для списков с несколькими видимыми строками теперь разное поведение.

🐞 **Исправлено**
— Поле поиска ровно по ширине списка — больше не «съезжает» на узких дропдаунах.
— Красный кружок с ошибкой теперь корректно ставится на ту ноду, по которой кликнули, и срабатывает один раз, а не по нескольку раз подряд.
