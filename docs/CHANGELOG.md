# История изменений

**Tags:** #bitrix24 #changelog #версии

---

## 1.4.0 (текущая)

- **Полная переработка архитектуры подсветки.** Отказ от оверлейного подхода (contenteditable / прозрачный textarea) — фундаментальная проблема несовпадения курсора и текста из-за различий в движках рендеринга оказалась неустранимой.
- **Новый подход — кнопка по требованию:** рядом с каждым `textarea` появляется маленькая кнопка `</>` (position:fixed). Клик открывает панель с подсвеченным текстом поверх textarea (position:fixed). Ещё клик или Escape — закрывает панель, фокус возвращается в textarea. Textarea не модифицируется вообще.
- **Добавлен background.js** (service worker): при перезагрузке расширения восстанавливает динамическую регистрацию content scripts для коробочных порталов (`chrome.runtime.onInstalled` / `onStartup`).
- **Исправлена кнопка «Добавить текущий портал»** в popup: после выдачи разрешения скрипт немедленно инжектируется в активную вкладку без перезагрузки страницы.
- **Упрощены стили:** удалены все overlay-классы, только `.bp-hl-btn` и `.bp-hl-panel`.
- Страница детальных настроек стала шире (max-width 640→960px).

## 1.2.4 (откат)

- Попытка ограничить бесконечный рост в «Добавить комментарий в элемент» (MAX_WRAPPER_PX) привела к поломке подсветки; изменения откатаны. Стабильная версия — 1.2.3.

---

## 1.2.3 (текущая стабильная)

- **Подход для полей из textarea:** один contenteditable div (`.bp-syntax-editable`) с подсвеченным HTML; скрытый textarea хранит значение для формы. Курсор и перенос строк совпадают с видимым текстом.
- Рамка у contenteditable: копирование границы из исходного textarea, цвет по теме (светлая/тёмная).
- Enter в contenteditable: `preventDefault`, `insertLineBreak` или `insertText('\n')`, затем обновление подсветки.
- ResizeObserver на textarea — начальные размеры обёртки; ResizeObserver на родителе обёртки — подстройка при изменении размера контейнера.
- Исключение поля «Заголовок» (id=`bpastitle` или name=`title`) из подсветки.
- **Ресайз перетаскиванием:** не реализован. Попытки (1.2.4–1.2.7) откатаны: ручка ресайза + изменение размеров обёртки приводили к конфликтам (двойная обёртка из-за attachHighlightToContentEditable, рассинхрон рамки и поля). Текущая версия без ручного ресайза.

## Более ранние вехи

- **1.2.0:** переход на contenteditable вместо overlay (textarea + слой pre/code) для полей выражений из textarea.
- **1.2.1:** исправление «узкого поля» (убраны принудительные 1×1 при скрытии textarea, запасные размеры при нулевых offsetWidth/offsetHeight).
- **1.2.2:** Enter и новая строка, подстройка под контейнер (ResizeObserver на родителе), исключение поля «Заголовок», рамка.
