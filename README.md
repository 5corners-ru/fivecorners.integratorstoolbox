# 5 УГЛОВ. Инструменты интегратора Bitrix24

Набор инструментов интегратора Bitrix24 в виде расширения для браузеров на базе Chromium (Chrome, Edge и др.).

**Текущие инструменты:**

- **Подсветка синтаксиса БП** — подсвечивает выражения в дизайнере бизнес-процессов: кавычки, запятые, фигурные скобки и конструкции вида `{=Document:...}`, `{{Переменная}}`.

**Версия:** 1.2.3 (см. `docs/CHANGELOG.md` и `docs/grammar-and-architecture.md` для разработки).

**Поддерживаются:** облачные порталы (*.bitrix24.ru, *.bitrix24.com и т.д.) и коробочные (добавляются в настройках расширения).

---

## Установка для локального тестирования (без публикации в сторе)

1. **Подготовьте папку расширения**  
   В папке должны быть файлы: `manifest.json`, `content.js`, `styles.css`, `options.html`, `options.js`. Дополнительные иконки не обязательны.

2. **Откройте страницу расширений в браузере**
   - Chrome: в адресной строке введите `chrome://extensions/` и нажмите Enter.
   - Edge: введите `edge://extensions/`.

3. **Включите режим разработчика**  
   Переключатель «Режим разработчика» (Developer mode) в правом верхнем углу страницы — включите.

4. **Загрузите распакованное расширение**  
   Нажмите «Загрузить распакованное расширение» (Load unpacked), в диалоге выберите **папку этого проекта** (ту, где лежит `manifest.json`). Браузер покажет расширение в списке.

5. **Проверка**  
   Откройте портал Bitrix24 (облачный или коробочный из списка в настройках), перейдите в дизайнер бизнес-процессов (Автоматизация → Бизнес-процессы → шаблон). В любом поле параметра действия введите, например: `{=Document:ID}` или `{{Переменная}}` — должна появиться подсветка кавычек, скобок и ключевых слов.

6. **Обновление после правок**  
   После изменения кода увеличьте версию в `manifest.json` (поле `version`), затем на странице `chrome://extensions/` нажмите кнопку «Обновить» (круглая стрелка) у карточки расширения.

**Примечание:** расширение установлено только локально; на другом компьютере или после переустановки браузера папку нужно указать заново. Для передачи коллегам можно отдать архив папки и эту инструкцию.

## Коробочный Bitrix24

1. Откройте **настройки расширения**: правый клик по иконке → «Настройки» или `chrome://extensions/` → ваше расширение → «Подробнее» → «Настройки расширения».
2. В поле «URL портала» введите адрес портала (например, `https://portal.5corners.ru`), нажмите **«Добавить»**.
3. Подтвердите запрос браузера **«Разрешить доступ к [сайт]»**.
4. **Обновите вкладку** с дизайнером БП (F5). Подсветка начнёт работать на этом домене.

Если панель с полями выражений открыта во фрейме с **другого поддомена** (например, `crm.portal.5corners.ru`), добавьте в настройках и его.

## Меню быстрого доступа (popup)

По клику на иконку расширения (справа от адресной строки) открывается меню:

- **Список сайтов** — все добавленные коробочные порталы; у каждого кнопки **Изменить** и **Удалить**.
- **Добавить текущий сайт** — добавляет в список origin открытой вкладки (удобно: откройте портал, нажмите на иконку расширения и эту кнопку).
- **Открыть полные настройки** — переход на страницу настроек, где можно вручную ввести URL.

После добавления или изменения сайта обновите вкладку с дизайнером БП (F5).

## Структура проекта и назначение файлов

| Файл | Назначение |
|------|------------|
| `manifest.json` | Манифест расширения (Manifest V3): разрешения, action (popup), content_scripts, страница настроек. |
| `popup.html`, `popup.css`, `popup.js` | Меню по клику на иконку: список сайтов, изменить/удалить, кнопка «Добавить текущий сайт». |
| `content.js` | Content script: проверка целевой страницы, поиск полей `textarea`, overlay-подсветка, токенайзер выражений БП. Подробно задокументирован в коде (JSDoc, комментарии). |
| `styles.css` | Стили классов подсветки (`.bp-syntax-string-double`, `.bp-syntax-brace` и т.д.). |
| `options.html` | Полная страница настроек: ввод URL вручную, список порталов. |
| `options.js` | Логика страницы настроек: сохранение списка, запрос разрешений, регистрация content script. |
| `README.md` | Этот файл: установка, использование, описание файлов. |

## Грамматика подсветки

Подсвечиваются:

- **Строки:** `"..."` и `'...'` (зелёный).
- **Фигурные скобки:** `{`, `}`, `{{`, `}}`, `{=` (красный, жирнее).
- **Круглые и квадратные скобки:** `(`, `)`, `[`, `]` (фиолетовый).
- **Запятая:** `,` (красный).
- **Ключевые слова:** `Document`, `Template` в контексте выражений (синий).
- **Двоеточие:** `:` (фиолетовый).

Остальной текст не раскрашивается. Алгоритм токенайзера описан в комментариях в `content.js`.
